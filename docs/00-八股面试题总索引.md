## 按技术分类速查

## 项目相关面试话术

### 自我介绍项目部分
"我做了一个企业级智慧医疗预约系统，后端Spring Boot 3 + Java 21，集成了Spring Cloud Alibaba微服务生态、Redis+Redisson分布式锁、RabbitMQ消息队列、多级缓存。前端Vue3 + TypeScript + Element Plus，分患者端/医生端/管理端。另外还有一个Python AI Agent，基于LangChain + RAG + Function Calling，给医生提供临床决策支持。"

### 项目亮点
1. 预约接口用Redisson分布式锁防超卖，结合幂等注解和限流
2. 订单超时用Redisson延迟队列+RabbitMQ死信队列双方案
3. AI Agent用ReAct架构，7个工具调用+RAG医学知识检索+SSE流式输出
4. 企业级规范：统一响应、全局异常、操作日志、三端权限
5. 管理端ECharts数据可视化看板
